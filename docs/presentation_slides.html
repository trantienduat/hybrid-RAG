Problem Statement

Vector RAG Limitations

Traditional retrieval-augmented generation relies on vector embeddings of text chunks. In source code, this ignores syntax, module inheritance, and call graph hierarchies, leading to incorrect multi-hop structural context.

Core Challenges

  • Syntax Blindness: Splitting code purely by line numbers destroys syntactic structure.
  • Entity Disconnection: Inability to resolve local function call stubs to global references.
  • Offline Requirements: Strict corporate data privacy mandates a fully offline, local environment.

Proposed Architecture: Hybrid-RAG

Graph + Vector Synergy

Combining the precise, structured syntax model of a Knowledge Graph (FalkorDB) with the semantic similarity search of a Vector Database (Qdrant).

Enables structural context walking (parent classes, sibling methods) alongside query-to-doc semantic retrieval.

Key Modules

  • Parser: Tree-Sitter parsing of modules, classes, and call-stubs.
  • Resolver: 3-step Entity Resolution (Sibling -> Module -> Global).
  • Retriever: Parallel structural Cypher query & vector distance search.
  • Ranker: Reciprocal Rank Fusion (RRF) with weighted parameters.

Ingestion & Global Entity Resolution

Ingestion Pipeline

Tree-Sitter parses source files into Abstract Syntax Trees (AST), mapping structural symbols to graph nodes (Modules, Classes, Functions, Variables).

Entity Resolution Steps

  1. Sibling Method: Look for a matching method inside the same class or its parent inheritance hierarchy.
  2. Module Context: Find defined functions inside the same source file.
  3. Global Fallback: If unique across the codebase, link globally.

Conclusion & Future Work

Key Takeaways

  • Offline Sovereignty: High-performance code understanding without leaking intellectual property.
  • Structure matters: Static AST graphs completely bridge the gap for multi-hop structural queries.
  • Hexagonal decoupling: Decoupled adapter layers support swapping storage engines effortlessly.

Future Work

  • Incremental Indexing: SHA-256 file diff tracking to skip redundant parse calls.
  • Hierarchical Summaries: Integration of directory-level summaries using Louvain community clustering.
  • Language expansion: AST extraction support for TypeScript, C++, and Go.

# Product Requirement Prompt (PRP) — FastAPI & Cyber-Dark Web UI

## 🎯 Role & Objective
You are an expert full-stack developer AI. Your task is to implement the **FastAPI REST API backend** and the **Cyber-Dark Web UI Visual Explorer** for the `hybrid-RAG` platform. The backend must serve indexing and retrieval APIs (including SSE streaming), and host static files. The frontend must render the codebase node graph interactively, allowing users to query, search, and inspect code relationships visually.

---

## 🏛️ Tech Stack & Styling
*   **Backend:** FastAPI, `uvicorn`, `httpx` (client calls to local Ollama).
*   **Frontend Core:** HTML5, CSS3, Vanilla Javascript. No heavy frameworks (React/Vue) or Tailwind CSS unless explicitly configured.
*   **Graph Rendering:** `cytoscape.js` (including layout extensions like `cose`, `circle`, `breadthfirst`).
*   **Design & Aesthetics:** Custom dark-mode system. Use curated harmonious color palettes (HSL variables: deep dark backgrounds, glowing cyan/purple node colors), premium typography (Outfit / Inter google fonts), glassmorphism cards, and subtle hover micro-animations.

## 🛠️ Functional Requirements

### 1. REST API Endpoints ([api/main.py](file:///Volumes/Kioxia_SSD/SSD_workspace/Personal/hybrid-RAG/src/hybrid_rag/api/main.py))
*   `POST /query`: Non-streaming query execution. Returns LLM response and structured source chunks.
*   `POST /query/stream`: Server-Sent Events (SSE) streaming endpoint. Yields JSON metadata (sources, query type) as the first event, followed by raw text tokens as they are generated by the local LLM.
*   `GET /graph/repositories`: Lists namespaces of indexed repositories in FalkorDB.
*   `GET /graph/neighbors/{node_id}`: Returns neighbors and relationships for a specific node to dynamically expand the UI graph.
*   `GET /graph/search`: Returns search results for auto-completion/quick lookups.
*   `GET /`: Serves the static `index.html` file.

### 2. Interactive Cytoscape.js Visualizer
On the webpage:
*   Render nodes matching labels: `Module` (blue), `Class` (purple), `Function` (green), `Variable` (yellow).
*   Render edges matching labels: `DEFINES` (solid gray), `CALLS` (dotted red), `INHERITS` (dashed purple), `USES` (glowing cyan).
*   Provide a **Layout Toggler** switching between circular layout (default, 3D-like cluster view) and breadthfirst layout (vertical hierarchical syntax trees).
*   Implement **Double-click to Expand**: Double-clicking a node fetches `/graph/neighbors/{node_id}` and merges new nodes/edges into the active graph viewport dynamically.

### 3. Floating Node Inspector
*   Create a side panel (glassmorphism overlay) that displays details of the selected node: FQN ID, label, file path, line numbers, docstring, source code snippet, and incoming/outgoing edges.
*   Include a query search tab allowing the user to select the query mode (structural, semantic, or hybrid), select a repository, type a question, and stream the answer into an output text box.
